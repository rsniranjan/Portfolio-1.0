# Niranjan — Creative Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It uses an editorial motorsport-inspired visual direction: oversized condensed typography, off-white/near-black surfaces, cyan accents, responsive project cards, scroll reveals, and an animated contour canvas.

## Files

- `index.html` — all page content and structure
- `style.css` — visual design and responsive layouts
- `script.js` — scroll progress, reveal animations, mobile navigation, cursor effect, and animated contour background

## Run locally

1. Extract the ZIP file.
2. Open the extracted `niranjan-portfolio` folder in Visual Studio Code.
3. Open `index.html`.
4. If you have the Live Server extension installed, right-click `index.html` and choose **Open with Live Server**. Otherwise, double-click `index.html` to open it in your browser.

The fonts load from Google Fonts when you have an internet connection. The page itself does not require a build step or package installation.

## Before publishing

- Update project links in `index.html` to point to the individual GitHub repositories when those repositories exist.
- Check the LinkedIn URL and other social links.
- If you want to add your own portrait, it can be added as a local image and integrated into the hero section.
- The SmartQueue and project descriptions are presented as project concepts; adjust the wording if the implementation status changes.

## Publish with GitHub Pages

1. Create a GitHub repository named `Portfolio` (or use your existing repository).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the deployment to finish. Your page should be available at `https://rsniranjan.github.io/Portfolio/`.

If the repository already contains an existing portfolio, make a backup before replacing its files.
